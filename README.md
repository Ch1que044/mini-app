# НИВА — Telegram Mini App

Мобильный каталог рыбы и морепродуктов с корзиной. Заказ отправляется с сервера прямо в личный чат владельца через Telegram Bot API. Токен бота хранится только в переменных окружения серверной платформы.

## Публикация

Проект рассчитан на Vercel: в репозитории должны находиться `index.html` и `api/order.js`. Подключите репозиторий к Vercel как проект без команды сборки и задайте две переменные окружения:

- `TELEGRAM_BOT_TOKEN` — токен вашего бота из BotFather.
- `TELEGRAM_OWNER_CHAT_ID` — ваш числовой Telegram ID (его можно узнать у `@userinfobot`). Телефон вместо ID не подойдёт.

После добавления/изменения переменных окружения нужно заново развернуть проект. Откройте вашего бота в Telegram и нажмите Start, чтобы он мог присылать вам заказы. Затем укажите публичный HTTPS-адрес опубликованной страницы в настройке Web App у вашего Telegram-бота.

`api/order.js` проверяет подпись и свежесть данных Telegram Mini App, сверяет товары и количества с каталогом, пересчитывает сумму на сервере и отправляет заказ в Telegram. Не добавляйте токен бота в HTML или клиентский JavaScript.

## Обновление каталога

Товары пока заданы вручную в `index.html`, а для серверной проверки заказа — в `api/order.js`. При изменении ассортимента или цен обновляйте обе таблицы. Интеграции с «МойСклад» пока нет.

Изображения товаров — встроенные SVG-заглушки, поэтому они отображаются без внешних фотосервисов и работают для каждой позиции.
